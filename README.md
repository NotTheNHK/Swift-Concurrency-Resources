Welcome! Here you will find a collection of official Swift concurrency–related resources. 
Each type of resource is organized into a separate file that guides you to the relevant materials (e.g., Swift Evolution proposals, WWDC videos).

- [Articles](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/Articles.md): Here you will find text-based resources written for Swift users.

- [WWDC Videos](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/WWDC-Videos.md): Here you will find audiovisual resources from Apple's annual WWDC conference. Valuable for all Swift users, regardless of platform.

- [Evolution Proposals](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/Evolution-Proposals.md): Here you will find in-depth, text-based resources explaining how and why the language works as it does. This category is primarily intended for language implementers and enthusiasts.
