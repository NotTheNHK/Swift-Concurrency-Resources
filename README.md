Welcome! Here you will find a collection of official Swift concurrency–related resources. 
Each type of resource is organized into a separate file that guides you to the relevant materials (e.g., Swift Evolution proposals, WWDC videos).

- [Articles](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/Articles.md): Text resources on Swift concurrency concepts and usage.

- [WWDC Videos](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/WWDC-Videos.md): WWDC talks covering Swift concurrency.

- [Evolution Proposals](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/Evolution-Proposals.md): Swift Evolution proposals related to Swift concurrency.
