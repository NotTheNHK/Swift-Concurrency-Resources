Welcome! Here you will find a collection of offical Swift concurrency related resources.
Each type of resource is organized in to a separate file guiding you to the resource (e.g., Swift Evolution Proposals, WWDC videos)

- [Articles](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/Articles.md): Here you will find text-based resources written for Swift users.

- [WWDC Videos](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/WWDC-Videos.md): Here you will find audiovisual resources from Apple valuable for all Swift users, regardless of platform.

- [Evolution Proposals](https://github.com/NotTheNHK/Swift-Concurrency-Resources/blob/main/Evolution-Proposals.md): Here you will find in-depth, text-based resources laying out how and why the language works as it does. This category is primarily for language implementers and enthusiast.
